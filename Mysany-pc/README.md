# MySANY 本地版（登录页 + 工作台 + 个人中心）

完全本地化运行：**双击 `index.html` 即可**，不需要服务器、不联网、运行期不发起任何 API 请求。
所有数据固化在 `data.js` 里。

## 使用

1. 打开 `index.html`（入口页，会自动跳到 `登录.html`；也可直接双击 `登录.html`）
2. 账号密码已预填：**admin / 123**（两个协议也已勾选）
3. 点「登 录」→ 进入 `工作台.html`

> 输错账号会提示；协议两个勾选框仍是各自独立授权，取消任一个登录按钮即置灰。
> 登录卡片里还有一个 **Cookies 设置** 入口，见下方「登录页的 Cookies 设置」。

## 已还原的内容

**协议变更页（`协议变更.html`）**
`工作台.html` 的副本，双击打开后**默认弹出**「更新提示」弹窗 ——
隐私协议 / 用户服务协议发生变更时要求用户重新同意，交互与 APP 端的
`privacy-update.html` 对齐：

- 弹窗标题「更新提示」，副标题「版本 v3.2 · 2026-09-29 生效」
- 正文列出本次更新的 4 条内容，其中《个人信息共享清单》可点开看全文
- **不可关闭**：点遮罩、按 Esc 都只提示「请先阅读并选择同意或拒绝」，没有 × 按钮
- 「同意用户服务协议」「同意隐私协议」两行**各自独立勾选**，
  两个都勾上「同意」按钮才变实心红；没勾就点会抖动并提示缺哪一项
- 两个协议名都能点开**阅读大弹窗**（复用工作台「设置」里的那一套 `.dlg-doc` 样式）
- **拒绝** → 二次确认「确认拒绝？」→ 仍然拒绝 → 退出态页面
  （可「重新查看协议」或「返回登录页」）
- 同意后写入 `localStorage` 的 `mysany.policy.agreedVersion = 3.2`，弹窗关闭，
  工作台恢复可用

> 本页是**演示页**，为了方便查看，每次进入都会弹窗（不读本地已同意记录）。
> 真实项目里应按「线上版本号 ≠ 本地已同意版本号」来决定是否弹出，
> 版本号在 `policy-update.js` 顶部的 `POLICY` 对象里。
> 三份协议正文同样是**本地示例文本，不是正式法律文件**，在同一个文件的 `DOCS` 里替换。

**登录页的 Cookies 设置**
登录卡片里、两行协议勾选下方新增一行 **「Cookies 设置 · 已启用 N / 4 类」**，
点击弹出的就是工作台里那一个偏好中心：

- 抽屉的样式与逻辑都来自 `cookies.css` / `cookies.js`，登录页和
  「工作台 › 个人中心 › 设置 › Cookies 设置」调用的是**同一份代码**，不是复制一份，
  改一处两处同时生效
- 读写的也是同一个 `localStorage` 键 `ms_settings`：在登录页选完，
  进入工作台打开「设置」看到的就是刚才的结果，反之亦然
- 行尾的「已启用 N / 4 类」会在抽屉关闭后立即刷新
- 抽屉正文为中文（与工作台保持一致）；登录页切到 English 时，只有入口这一行会跟着变

**Cookies 偏好中心**（参考通用同意管理面板的交互样式）
- 480px 右侧抽屉，滑入动画
- 顶部 logo + × 关闭；正文含「首选项中心」说明与「浏览器设置」段落
- 「管理许可偏好」右侧有 **全部允许** 按钮
- 4 个手风琴分类卡片，点标题行 `+ / −` 展开详细说明：
  - **绝对必要的 Cookie** —— 显示「始终处于活动状态」，无开关
  - **功能 Cookie / 性能 Cookie / 定向 Cookie** —— 各自独立开关
- 点开关**不会**误触展开手风琴（已做事件隔离）
- 每个分类展开后有 **「Cookie 详细信息 ›」**，点进去是 **Cookie 列表** 页：
  - 顶部返回箭头 + 「Cookie 列表」，下方显示分类名与条目数
  - 按**主机分组**的手风琴（第一方 Cookie / 各第三方域名）
  - 展开后每条 Cookie 一张卡片，含 **名称 / 主机 / 持续时间 / 类型 / 类别 / 说明** 六项
  - 底部按钮保持不变，随时可确认或拒绝
- 底部固定：**全部拒绝** / **确认我的选择**，两者都会立即写入并回到设置弹窗

- 设置弹窗底部「保存 / 取消」管的是个性化广告：保存写入 `localStorage`，**取消不生效**
- 关闭方式：保存、取消、右上角 ×、点遮罩、按 **Esc**
- 所有偏好刷新后保持

> **Cookie 清单**在 `data.js` 的 `cookies` 字段里，按四个分类组织，可直接增删改。
> 其中「必要 / 功能」两类是本地页面**真实使用**的存储项（`ms_settings`、`mysany_lang`、
> `ms_collapsed`、`ms_open`、`ms_route` 等）；「性能 / 定向」两类本地页面并不会写入，
> 是**示例条目**，域名用的是保留示例域名 `example.com`。接入真实统计/广告服务后请替换。

> 两份协议正文是**我写的本地示例说明文本**，用于演示交互，
> 已在弹窗顶部标注「不是正式法律文件」。**不能当作正式条款使用**，
> 需要正式文本请从官方渠道获取后替换 `wb.js` 里的 `DOCS` 对象。

**其他**：退出登录回到 `登录.html`；菜单、折叠状态、当前页刷新后保持。

## 改数据

只改 `data.js`，比如换个人信息：

```js
user: { name: '张三', phone: '138****0000', email: 'a@b.com', role: '设备管理员', ... }
```

审核卡片数字、事件列表、消息、快速链接、菜单项同理，都在 `data.js` 里。

## 说明

- 这是**独立的本地静态页面**，不是线上系统的离线镜像：HTML/CSS/JS 全部重新实现，
  没有搬运线上打包产物，因此代码干净、可读、能继续改。
- 数据是抓取当时的快照，不会自动更新。
- 左侧菜单依据 2026-10-08 测试环境企业租户账号的 Web 菜单权限整理；
  APP 专属入口和按钮级权限不会出现在 PC 左侧导航中。
