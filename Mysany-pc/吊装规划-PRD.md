## 一、需求背景与目标

### 1.1 背景

1. 平台现有「重卡车队运营」等模块聚焦于运输车辆运营管理，缺少面向**履带起重机吊装作业**的规划能力入口。
2. 吊装规划（SANY SMART LIFT）作为独立业务系统，需要在 MySANY 平台侧拥有统一入口，用户登录后可直接从左侧导航进入。
3. 首期仅做**入口打通 + 首页框架**：以吊装工作台首页（SMART LIFT 首页）为原型。

### 1.2 目标


| 目标      | 说明                                         |
| ------- | ------------------------------------------ |
| 导航入口统一  | 左侧导航「重卡车队运营」下方新增一级目录「吊装规划」，点击进入吊装规划页面      |
| 与平台壳架一致 | 保留 MySANY 顶栏（消息/语言/租户/用户）与左侧主导航，可与其他模块互相跳转 |


---

## 二、导航与入口

### 2.1 菜单结构变更

左侧导航在「重卡车队运营」分组之后新增一级菜单项：

```text
重卡车队运营（分组，二级：运营大屏/车队仪表盘/…）
吊装规划（一级，无二级，点击直接进入）   ← 本期新增
```


| 项      | 说明                                 |
| ------ | ---------------------------------- |
| 菜单 key | `lift-plan`                        |
| 菜单名    | 吊装规划                               |
| 图标     | 吊钩造型线性图标（与其他菜单同规格：1.8 描边、24×24 视图） |
| 菜单类型   | 一级菜单，无子菜单；点击即跳转 `吊装规划.html`        |

## 五、验收标准

1. 登录进入工作台，左侧导航「重卡车队运营」下方可见一级目录「吊装规划」，带吊钩图标。
2. 点击「吊装规划」打开 `吊装规划.html`。
