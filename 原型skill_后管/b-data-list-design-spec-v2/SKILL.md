# MySANY 管理平台 — 列表页设计规范

> V3：全面对齐**三一 MySANY 后台管理平台**真实线上界面。
> 数值取自线上产物 CSS（按真实加载顺序重建层叠后取最终生效声明），并与线上页面截图逐像素比对校验。
> 此前版本基于"可信数据空间"Figma（主色 `#255CE9`、顶栏 56px、侧栏 240px、浅色外壳）——**已全部作废**。

## 这套系统长什么样（先记住这五条）

1. **深色导航壳**：顶栏 `#172742` 高 48px，侧栏 `#1e3255` 宽 220px，内容区浅色 `#f4f5f7`。
2. **主色是青蓝 `#29bece`**，不是蓝色。（choerodon-ui 原厂主色 `#3f51b5` 已被三一覆盖。）
3. **基准字号 12px**，不是 14px。**控件高度 28px**，表格行高 36px。信息密度高。
4. **圆角只有 2px**，内容卡无圆角、无阴影。
5. **必填项用淡黄底 `#feffe6` 表达，不是红星号**（该部署显式关闭了星号）。

## 何时使用

- 按本规范还原/新建 MySANY 后台的列表页、详情页、审核页
- 审查现有页面是否符合该后台的设计语言
- 需要查某个组件（按钮/表格/弹窗/表单控件）的精确尺寸与配色
- 需要判断该用弹窗还是抽屉、状态该用圆点还是 Tag

## 核心流程

### 第一步：加载参考文件

- `references/tokens.md` — **唯一数值真源**。所有颜色、字号、间距、尺寸只能从这里取值。
- `references/components.md` — 每个组件的精确规格、class、HTML 片段与各状态。
- `references/scenarios.md` — 场景选择、弹窗/抽屉决策、列设计、操作位置、反馈规则。

### 第二步：接入基础样式

1. 引入 `assets/templates/assets/sany-ui.css`（完整组件实现，含 Design Token）。
2. 在**所有页面样式之后**引入 `assets/templates/assets/shell/shell-lock.css`。
3. 图标使用模板内的内联 SVG 雪碧图（Material 图标名，`currentColor` 着色），不要引入第三方图标库。

> `assets/templates/assets/shell/` 下的旧 SVG（`settings.svg`、`bell.svg`、`avatar.svg` 等）属于已作废的
> Figma 浅色外壳，**不再被引用**，详见该目录的 `DEPRECATED.md`。

### 第三步：复制锁定 Shell

从 `assets/templates/full-reference.html` 原样复制所有 `[data-locked-shell="true"]` 区域：

- 顶栏：logo + 平台名 + 折叠按钮 + 右侧（站点选择／语言／消息铃／头像用户名）
- 侧栏：菜单搜索框（`#425370` 底）+ 菜单列表（项高 44px，可展开项带右箭头）

**仅允许替换可见文字**（平台名、菜单名、用户名、站点名）。
禁止改变 DOM 层级、类名、尺寸、间距、颜色、圆角、选中态、图标尺寸与位置；
禁止通过组件参数、主题变量、CSS 变量、工具类、CSS-in-JS、内联样式或后加载样式覆盖锁定 Shell。

菜单选中态是 **5px 实心 `#29bece` 左条 + 向右渐变至 `#29bece`**，不是浅色块，不要简化。

### 第四步：选择页面场景

从 `references/scenarios.md` 选择**最小匹配**场景，只裁剪所需区块，
不要把 `full-reference.html` 的多场景并排结构带进生产页面：

1. **标准列表页**：页头 → 查询区 → 工具栏 → 表格 → 分页
2. **分类列表页**：页头 → 页内下划线 Tab → 查询区 → 工具栏 → 表格 → 分页
3. **主从/详情页**：列表 + 右侧抽屉详情，或独立详情页（描述列表 + 分组卡片）

多页签栏（顶栏与页头之间、36px、选中页签 `#f0f0f0` + 主色字）是该平台的特征元素，
在需要体现多任务导航时加入。

### 第五步：组合组件

按 `references/components.md` 的规格组合。固定的版面节奏：

- 页头 `.page-head` 48px，标题 16px，操作按钮在**右侧**
- 内容卡 `.page-content`：`margin:8px 16px 16px`、`padding:16px`、纯白、无圆角无阴影
- 查询区：`table + colgroup`，label 列 **80px 右对齐带冒号**，按钮顺序 **更多 → 重置 → 查询(主)**，整体右对齐
- 工具栏：主操作（新建/导出）靠左
- 表格：行高 36px，表头 `rgba(0,0,0,.04)` + `font-weight:700`
- 分页：右对齐，文案 `每页行数：` 与 `1 - 20 / 45`

### 第六步：严格取值

所有颜色、字号、间距必须来自 `references/tokens.md`，不得自创。核心值：

| 项 | 值 |
|---|---|
| 主色 / hover | `#29bece` / `#1995a8` |
| 顶栏 / 侧栏 | `#172742` / `#1e3255` |
| 画布 / 卡片 | `#f4f5f7` / `#fff` |
| 正文 / 边框 / 输入框边框 | `#333` / `#e0e0e0` / `#d9d9d9` |
| 错误 / 必填底 | `#d50000` / `#feffe6` |
| 基准字号 / 圆角 | 12px / 2px |
| 控件高 / 行高 | 28px / 36px |

## 设计原则

1. **一致性**：同一套 `sany-ui.css`，组件不随意变形。
2. **高密度**：12px 字号 + 28px 控件 + 36px 行高是刻意的紧凑，不要"为了好看"放大。
3. **克制**：主色只用于主按钮、选中态、链接与强调；不引入装饰色、渐变（菜单选中态除外）、大圆角、卡片阴影。
4. **深浅分明**：导航深色、内容浅色，这是该平台的识别特征，不可改为全浅色。
5. **反馈完整**：所有可交互元素必须有 hover / focus-visible / active / disabled 态；危险操作二次确认；提交后 message 提示。
6. **1440px 基准**：以 1440px 验收；内容区流式占满侧栏右侧空间，侧栏可折叠至 60px。
7. **必填即黄底**：必填控件加 `.is-required`（淡黄底），不渲染红星号，除非业务明确要求。
8. **Shell 不可变**：顶栏与侧栏属于基础视觉 Shell，任何视觉或结构变更视为阻断性缺陷。

## 输出规范

生成的页面必须是可直接运行的独立 HTML（或对应框架组件），包含：

1. 引入 `sany-ui.css` + `shell-lock.css`（或将其内联，但数值必须一致）
2. 完整的锁定 Shell
3. 真实可用的交互：查询展开/收起、行选择与全选（含 indeterminate）、排序、分页、弹窗/抽屉开关（含遮罩点击与 Esc 关闭）、消息提示
4. 完整的状态：hover、focus、disabled、加载、空数据、校验错误

- [ ] 基准字号 12px，控件 28px，表格行高 36px
- [ ] 圆角均为 2px，内容卡无阴影
