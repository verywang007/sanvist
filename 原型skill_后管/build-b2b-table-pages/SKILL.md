# 构建 MySANY 后台表格页

按语义区块与可复用组件构建，不要复刻绝对定位。

> 本规范对齐**三一 MySANY 后台管理平台**线上真实界面，数值取自线上产物 CSS（按真实加载顺序重建层叠取最终生效声明），并与线上截图逐像素校验。
> 旧版"可信数据空间"Figma 规范（`#255CE9`、顶栏 56px、侧栏 240px、控件 36px、14px 字号、大圆角、浅色外壳、强制面包屑）**已全部作废**。

## 五条先记住

1. 深色导航壳：顶栏 `#172742`/48px，侧栏 `#1e3255`/220px，画布 `#f4f5f7`。
2. 主色 **`#29bece`**（青蓝），hover `#1995a8`。不是蓝色。
3. 基准字号 **12px**，控件 **28px**，表格行高 **36px**。
4. 圆角只有 **2px**，内容卡无圆角无阴影。
5. 必填用**淡黄底 `#feffe6`**，不是红星号。

## 工作流程

1. 检查目标仓库与其框架、既有外壳/表格/表单/按钮/弹窗/Token 组件，优先复用。
2. 阅读 [references/table-page-spec.md](references/table-page-spec.md)。
3. 选择**最小匹配**场景并从页面内容自行推断，不要在生产页面渲染场景切换器或结构选择器：
   - 纯表格
   - 带查询表格
   - 带页内 Tab 分类表格
   - 带指标卡表格
   - 带说明文案表格
   - 含弹窗表格
4. 复用仓库组件与 Token；若无既有前端体系，复制 [assets/table-page-template/index.html](assets/table-page-template/index.html) 并改造。
   `assets/sany-ui.css` 与 `assets/shell/shell-lock.css` **原样保留**，只改造锁定区域之外的内容。
5. 实现必要状态：hover、active、focus-visible、加载、空数据、错误、禁用、分页、查询折叠、弹窗开关。
6. 对照 [references/acceptance-checklist.md](references/acceptance-checklist.md) 自查。先按 1440px 验收，再检查更窄的桌面宽度。

## 不可协商的规则

### 外壳
- 顶栏与侧栏为不可变外壳。原样复制 `[data-locked-shell="true"]` 区域与 `assets/shell/shell-lock.css`，且 `shell-lock.css` 必须**最后加载**。
- 仅允许替换可见文字（平台名、菜单名、用户名、站点名）。不得改动 DOM 层级、类名、尺寸、间距、颜色、圆角、选中态、图标尺寸与位置。
- 不得暴露外壳的样式属性、主题覆盖、类名覆盖或可配置 Token。
- 菜单选中态为 **5px 实心 `#29bece` 左条 + 向右渐变至 `#29bece`**，项高 44px，不得简化为浅色块。
- 侧栏搜索框底色 `#425370`，高 28px。
- **不要渲染面包屑**——该平台用"多页签栏 + 页头标题"承担导航定位，线上页面没有面包屑。

### 版面
- 区块顺序：页头 → 可选说明文案 → 可选指标卡 → 可选查询区 → 工具栏 → 表格 → 分页。
- 页头 `.page-head` 48px，标题 16px `#000`，操作按钮在**右侧**。
- 内容卡 `.page-content`：`margin:8px 16px 16px`、`padding:16px`、纯白、**无圆角无阴影**。
- 主内容流式，不得把 1440px 写死到应用根节点。

### 查询区
- 用 `table + colgroup` 布局：label 列固定 **80px**、右对齐、带冒号；字段列自适应。
- 一行放 3–4 组 label+字段；**默认只显示第一行**，其余行加 `.s-query-row-overflow` 由「更多」折叠。
- 按钮固定顺序与位置：**更多 → 重置 → 查询（主按钮）**，整体右对齐。
- 「更多」展开后文案变「收起」，箭头旋转 180°。

### 表格
- 行高 36px；表头底色 `rgba(0,0,0,.04)`、`font-weight:700`、字色 `rgba(0,0,0,.85)`。
- 单元格 `padding:0 10px`（定高行）或 `5px 10px`（折行态，加 `.s-table.is-wrap`）；线 `1px solid #e0e0e0`。
- 行 hover `rgba(0,0,0,.04)`；选中行 `rgba(140,158,255,.12)`（`.is-selected`）。
- 每行行首放选择复选框，表头首格放全选框，并正确维护 `indeterminate`。
- 数值列加 `.s-col-num`（右对齐 + `tabular-nums`），状态列可用 `.s-col-center`，操作列在**最右**。
- 行内操作用文字按钮 `.s-btn-flat`；危险操作加 `.is-danger` 并二次确认。
- 仅给真正可排序的列加 `.s-sort`，不要给每列都加。
- 超长内容用 `.s-ellipsis` 省略，不要撑破列宽。
- 必须实现空状态 `.s-empty` 与加载态 `.s-loading`。

### 分页
- 右对齐，`margin-top:10px`。
- 结构与文案固定：`每页行数：` + 每页条数下拉 + `1 - 20 / 45` + 四个 flat 图标按钮（首页/上页/下页/末页），首尾在边界时 `disabled`。

### 弹窗
- 宽 520px；头 `15px 24px`，标题 18px/500；体 `24px`；脚 `12px 24px` 右对齐。
- 底部**主按钮在最右**，取消在其左。遮罩 `rgba(0,0,0,.288)`，支持遮罩点击与 Esc 关闭。

### 取值
- 主色 `#29bece`、hover `#1995a8`；画布 `#f4f5f7`；卡片 `#fff`；正文 `#333`；表格线 `#e0e0e0`；控件边框 `#d9d9d9`；错误 `#d50000`；必填底 `#feffe6`。
- 除语义化的错误色外，不要引入任何装饰色；本系统**没有**统一的 success 绿 / warning 橙色板，状态用圆点或主色 Tag 表达。
- 不得出现 `#255CE9`、14px 基准字号、32px 以上控件高度、大于 2px 的圆角、卡片阴影。
